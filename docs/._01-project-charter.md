# 项目章程 – 校园活动报名与签到管理系统

## 项目名称
校园活动报名与签到管理系统

## 项目背景
学
我校拟建设一套轻量级系统，用于支持活动信息发布、学生报名、名单审核、二维码签到及签到统计导出。当前缺乏统一管理工具，活动组织效率低、签到记录不完整。本项目旨在通过信息化手段提升活动组织效率与数据准确性。

## 项目目标
- 支持活动管理人员发布活动并维护报名时间、人数上限、活动地点。
- 支持学生查看活动并在线报名。
- 支持活动组织者审核报名名单。
- 支持现场二维码签到并生成统计结果。
- 支持签到统计导出（Excel/CSV）。

## 高层级需求
- 活动信息发布与维护
- 学生报名与个人报名查询
- 报名名单查看与审核
- 签到记录与状态管理
- 签到统计导出

## 成功标准
- 完成所有项目管理文档（WBS、进度计划、配置管理、总结报告）
- 仓库结构清晰，分支策略合理，提交记录完整
- 成功制造并解决一次Git冲突
- 所有文档合并至main分支并通过检查

## 主要干系人
- 活动管理员：发布活动、查看统计
- 学生：报名、查询结果
- 现场签到人员：核验身份并签到
- 系统维护人员：配置系统参数
